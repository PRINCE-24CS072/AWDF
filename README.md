# AWDF Practical Repository

This repository is organized so each practical can be deployed as an independent project on Vercel.

## Folder structure

- Practical-1/ - React + Vite app
- Practical-2/ - Static HTML/CSS/JS starter
- Practical-3/ - Static HTML/CSS/JS starter
- Practical-4/ - Static HTML/CSS/JS starter

## Vercel deployment

For each practical, create a separate Vercel project and set the project root to the practical folder.

- For React + Vite projects: use the Vite preset, build command `npm run build`, output directory `dist`
- For static HTML projects: no build step is required

## Adding a new practical

Create a new folder named `Practical-5/`, `Practical-6/`, and so on, and place that practical's app files inside it.
